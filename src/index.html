Servidor ligero, asíncrono y de alto rendimiento. Ideal para APIs REST.

MySQL

Docker & Compose

Contenedores aislados para base de datos, app y proxy. Despliegue en minutos.

Características Técnicas

Backend listo para producción y fácil de integrar

Seguridad

  • Autenticación JWT con tokens de acceso y refresco
  • Roles: cliente, admin, superadmin
  • Validación de input con express-validator
  • Protección contra SQL Injection y XSS
  • Rate limiting básico (express-rate-limit)

Arquitectura

  • Capas: models, routes, controllers, services
  • Conexión a MySQL con pool de conexiones
  • Manejo de errores centralizado
  • Logging básico con Winston (opcional)
  • Código limpio, documentado y con ESLint

Webhooks & Eventos

  • Notificaciones en pedidos (pendiente, pagado, enviado)
  • Webhooks configurables para integraciones externas
  • Simulador de eventos incluido

DevOps

  • docker-compose.yml para entorno local
  • Variables de entorno (.env)
  • Scripts de npm para migraciones y seeders
  • Compatible con CI/CD (GitHub Actions)

Endpoints Principales

RESTful, bien documentados y listos para consumir

Autenticación

POST /api/auth/register
POST /api/auth/login
POST /api/auth/refresh

Productos

GET /api/products
GET /api/products/:id
POST /api/products (admin)
PUT /api/products/:id (admin)

Usuarios

GET /api/users/profile
PUT /api/users/profile

Pedidos

GET /api/orders
POST /api/orders
GET /api/orders/:id
